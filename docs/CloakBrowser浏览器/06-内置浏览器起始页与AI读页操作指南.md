## 1. 背景与目标

把「内置浏览器」从"能上网的镜像面板"升级成"用户真正的起始页浏览器 + AI 可读页"：

1. 点「内置浏览器」→ 自动打开 **iTab 网页版起始页**（`https://web.itab.link/`），
   用户可直接在面板里搜索、点击、上网（键鼠转发既有能力）；
2. 用户在浏览器里打开 B 站视频后，回到对话框说"将我当前打开界面的内容总结一下"，
   **agent 调用新工具 `browser_read_current` 读取共享会话页**（URL/标题/可见正文，
   带用户登录 Cookie），LLM 输出总结。

架构上不需要新浏览器：面板与 agent **共享同一个 CloakBrowser 会话页**
（02 §1 收口原则），缺的只是"默认首页"与"读当前页的工具入口"两小块。

## 2. 原理

### 2.1 起始页（面板侧）

```
无会话页的三个时机：面板挂载 probe / 点「启动浏览器」后 / 标签全关·agent 结束会话
  → goHome()（防重入 ref，同一时刻只有一班首页导航在飞）
  → debug_navigate(PANEL_HOME_URL)   PANEL_HOME_URL = https://web.itab.link/
  → iTab 渲染（搜索框/时钟/天气/壁纸）→ 用户键鼠操作与普通网页无异
```

iTab 是扩展产品，其**网页版** `web.itab.link`（title=新标签页）实测在 headless
Cloak 下完整渲染（搜索框 `input[placeholder=输入搜索内容]`、时钟、日期、天气组件）。
用户关掉最后一个标签、或 agent 结束会话（`debug_close`）后，帧循环发现无页 →
同样自动回首页，与真实浏览器"回到新标签页"一致。

### 2.2 agent 读当前页（工具侧）

新工具 `browser_read_current`（`cloak/plugin/tools/browser-read.js`，
注册进 `dsh-cloakbrowser` 常规工具集，与 `cloak_fetch` 并列）：

```
execute()
  → ensureService()：探测派生端口（crc32(projectRoot)，本安装为 27033）上的
    browser_server；无则 spawn pythonw browser_server.py（windowsHide，等 READY）——
    与 bridge 同端口同算法，天然复用同一实例
  → panel_state：has_page? （无页报错"用户当前没有打开页面"）
  → debug_evaluate：(() => ({href, title, text: document.body.innerText}))()
  → 截断 128KB（与 cloak_fetch 同预算）返回 url/title/chars/truncated/text
```

读的就是用户正看着的那一页（含登录态），**不新开、不关闭、不导航**任何页面。

## 6. 回退方式

- 起始页：删 `PANEL_HOME_URL` 相关三处（probe/NO_PAGE 分支的 `goHomeRef.current()` 与
  goHome 定义），恢复"无页时显示输入提示"；
- 读页工具：`cloak/plugin/index.js` 删注册行即可（工具文件可留存）。

## 7. 已知限制与遗留

1. **goHome 与用户导航并发的误报浮条**（低概率）：首页导航在飞（6s settle）时用户
   立即输入新地址，服务端两个 `debug_navigate` 并发，前者的等待会因页面被替换而
   报错——**页面实际已正确到达目标**，浮条属误报。`homeFlightRef` 只防"多次
   home"，不防 "home vs 用户导航"。改进方向：用户 navigate 时作废在飞 goHome，
   或服务端串行化 `debug_navigate`。
2. **"总结"的语义边界**：`browser_read_current` 返回页面可见文本（标题/简介/评论等），
   不是视频音频内容本身；B 站多数视频用页面文本+简介已可得不错总结，需要"逐句
   字幕总结"时可再加字幕接口抓取（另议）。
3. **无页状态语义**：工具在无页时明确报错（agent 会转告用户先打开页面），
   不会擅自导航。
4. **既有遗留不回归**：每次 start 双 browser_server 进程（05 §7.3）、
   cloakserve 接管/rmtree（02 §8.5.4）——本轮未触碰相关代码。
5. **iTab 网页版 vs 扩展版**：当前用网页版 URL。iTab 官方 crx 离线版可通过
   cloakbrowser 的 `--load-extension` 加载成"真·新标签页"（连浏览器原生新标签
   都替换），体验更正宗——本期未做，留作升级选项。
