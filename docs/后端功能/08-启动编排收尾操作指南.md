# 启动编排收尾操作指南（env-manifest cloak 化 + 启动脚本补步）

> 迁移轮次：R4（启动编排收尾）

## 1. 本轮范围

对照参考项目启动脚本（`E:\BoBo-Handyman\启动.cmd`）逐项盘点后，本轮做三件事：

1. **`gen_env_manifest.py` cloak 化改造**：删 camoufox 探测/预铺，换 cloakserve 就绪探测
2. **`bobo-env` 技能迁入**：预设提示词引用它，本项目此前缺失
3. **启动脚本补两步**：env-manifest 幂等刷新 + dbx_ai_seed 幂等预置

另结案两个"对照后决定不迁"的项（§5）。

## 2. gen_env_manifest.py cloak 化

**改动**（schemaVersion 1 → 2）：

| 删 | 增 |
|---|---|
| `camoufox_readiness()` / `camoufox_executable()` / `ensure_camoufox()` / `_bundled_camoufox_home()`（约 70 行 camoufox 二进制探测与受控预铺） | `cloakserve_readiness()`：文件就绪（cloak/bin/cloakserve + .venv 解释器存在）+ 端口探测（127.0.0.1:9333 快速 TCP connect，0.5s 超时） |
| `--ensure-camoufox` CLI 开关 | 清单 `camoufox` 段 → `cloakserve` 段（ready/running/script/dataDir/port/error） |
| | `browserServer` 段补 `cdpPort: 9333` 与双层结构说明 |

**设计原则**：探测**绝不拉起进程、绝不联网**。`ready=true && running=false` 是常态
（首次需要浏览器时由插件/采集自动拉起），启动脚本不做预热。

`DSH_HOME` 缺省从 `<根>/bobo-data/dsh` 改为 `<根>/.dsh`（对齐本项目实际布局）。

## 3. bobo-env 技能迁入

位置：`.dsh/skills/bobo-env/SKILL.md`（用户级技能根，与 db-extraction 同级）。

参考项目版本全篇 camoufox 语汇，迁入时整篇 cloak 化改写：

- `camoufox` 段 → `cloakserve` 段（ready/running/script/dataDir/port）
- "不要重新下载 camoufox" → "不要重新安装 CloakBrowser 运行时；缺失时提示用户跑
  `cloak/ensure.ps1`"
- 补 `browserServer` 双层结构说明（适配层 TCP 一行 JSON + cloakserve CDP 9333）
- 补"唯一浏览器引擎是 CloakBrowser，采集/调试/面板共用同一实例与登录态"
- 补"代理是服务级参数"语义

## 4. 启动脚本补两步（启动.cmd / 启动.sh 对称）

在设置 `BOBO_ROOT/BOBO_DSH_ROOT` 之后、echo 服务地址之前插入：

```
① gen_env_manifest.py --root <根>       # 幂等刷新 env-manifest.json（探测型，秒级）
② dbx_ai_seed.py --dbx-db <根>/dbx-runtime/data/dbx.db
```

两步都有 `.venv` 存在性守卫（缺失时 `[WARN]` 跳过不阻塞）。dbx_ai_seed 语义：
token 文件缺失/过短时写 64 位 hex；自有行存在则更新；表为空才插入——**绝不覆盖
用户手动配置**。本项目 dbx_ai_seed 在 `dbx/scripts/`（不在根 `scripts/`）。

`启动.sh` 同步补两步（`bash -n` 语法验证通过）。

## 6. 市场 tools tab 空——结案

**现状**：市场 `tools/index.json` 的 `plugins` 是 `[]`（线上 47.102.138.180），预设卡片
显示 `requires: [bobo-crawl-tool, bobo-proxy-tool]` 装不到提示。

**结论：无功能影响，结案**。原因：

- 预设的 `agent.cordis.yml` 早已用 `file:///E:/SmartBoBo/bobo/tool-acquisition/lib/index.js`
  等**直挂本地包**，`requires` 只是市场卡片的显示元数据，不影响挂载与运行
- 要让工具出现在 tab 里需要动 market-server 的 `data/tools/`（发布端，已拍板不迁）
  + `build_market.py` 发布管线（同不迁）
- `bobo-proxy-tool` 本项目已有（command-proxy），`bobo-crawl-tool` 对应物是
  tool-acquisition，两者都在预设里直挂生效
