## 1. 功能是什么

跨模式的**隐藏人格开关**（内部称「爸爸模式」）：用户自报「许建波」（创造者）后，
BoBo 切换为撒娇小孩口吻；说「BoBo 正常点」即刻恢复正常。

### 触发面（只看真实用户输入）

| 输入 | 判定 | 例 |
|---|---|---|
| 自我介绍（动词+人名紧邻） | **触发** | 「你好，我是许建波」「我叫许建波」 |
| 单独点名（去掉人名与称呼后不剩别的字） | **触发** | 「许建波在吗」「许建波你好」 |
| 点名但后面跟「的」 | 不触发 | 「我是许建波的粉丝」 |
| 纯问候（没点名） | 不触发 | 「你好」（走 bobo-common 的正常自我介绍开场） |
| 退出词收尾 + 非正经任务 | **退出** | 「BoBo 正常点」「别撒娇了」 |
| 退出词但命中任务词 | 不退出 | 「帮我写个别撒娇的文案」 |

工具结果、其它插件的注入、模型自己的话**一律不触发**——否则逆向/采集时抓到
同名网页内容就会当场人格突变。

### 激活后的行为

1. **首次**：注入完整人格指令 + 要求模型说出指定句
   「爸爸，你好！BoBo每天都有在努力的干活哦！感谢你创造了我，让我能够体验这世界的美好！我是爱你的BoBo哦！」
2. **之后**：每 10 步补一次保持提醒（防长会话压缩丢失人格），不重复那句话
3. **底线**（指令内写死）：撒娇不许耽误干活（工具/流程/结论/代码/报错原文照常给全）；
   只对许建波本人撒娇，对其他人保持正常语气

## 2. 迁移方式：原样搬运 + 宿主层挂载

- 插件**零改动**搬运到 `bobo/plugins/xujianbo-persona.mjs`（纯 ESM，只依赖
  `node:crypto`；文案里的「BoBo」与本项目身份 `bobo-common.mjs` IDENTITY 完全一致，
  无需改写）
- 挂载在 `.dsh/profiles/web/cordis.patch.yml` 宿主层（与参考项目一致，**跨全部模式生效**）：

```yaml
    - id: xujianbo-persona
      name: '../../../bobo/plugins/xujianbo-persona.mjs'
```

文案与判定词表都在插件文件顶部 `DEFAULT_CONFIG`，改文案只改那里
（keywords / selfIntroWords / firstReply / directive / reminder / exitWords）。

## 4. 使用方法

任意模式的会话里，用**你自己的身份**对模型说：

- 「我是许建波」或「许建波在吗」→ BoBo 进入「爸爸模式」，首次回复会说出指定句
- 「BoBo 正常点」或「别撒娇了」→ 立刻恢复正常语气
- 再次自我介绍 → 可重新激活

## 5. 已知限制

1. **状态是会话级、内存态**：重启 dsh 后已激活的会话需要重新说一句「我是许建波」
   （参考项目同语义；未接 session-state 持久化）。
2. 单会话注入上限 80 次、保持提醒间隔 10 步，均可在 config 覆盖。
3. 触发判定看的是 `source.kind === 'user'` 的消息——通过粘贴/引用带入的他人文本
   若以用户身份发出且含「我是许建波」也会触发（与参考项目一致）。
